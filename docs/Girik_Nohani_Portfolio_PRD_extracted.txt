8.11 Editable Text — How Portable Text Works
Any field typed as 'array (Portable Text / block content)' in Sanity renders a rich text editor in the Studio — similar to a minimal Google Docs. The client can:
Bold or italicise words
Add hyperlinks to any word or phrase
Create paragraph breaks
Add bullet lists (if enabled in the schema)
In the Next.js code, render these fields using @portabletext/react with 
a custom components
 map that applies the correct Tailwind classes for the site's typography. Never render Portable Text as raw HTML strings.
Fields that should be Portable Text (rich): bio, 
caseStudyBody
, 
contactIntroText
, service descriptions, certification descriptions.
Fields that should be plain text (no formatting): 
heroTagline
, all CTA labels, nav labels, meta title/description, company names, degree names.
9. API Routes
9.1 POST /
api
/contact
Handles contact form submission. Validates fields, then sends a formatted email to the client via Resend.
Method: POST
Body: 
{ name
: string, email: string, subject: string, message: string }
Validation: all fields required, email must be valid format
On success: sends email via Resend to client's inbox, returns 
{ success
: true }
On error: returns 
{ error
: string } with appropriate HTTP status
Email template: use React Email — include sender name, email, subject, message body in a clean HTML template
Rate limiting: basic — reject if same IP submits more than 3 times in 10 minutes
10. Animation Specifications
All animations use Framer Motion. Keep motion subtle — this is a professional portfolio, not a game.
10.1 Page Load Sequence
Nav fades in: delay 0ms, duration 400ms
Hero label fades in: delay 200ms, duration 400ms
Hero name typewriter: starts at delay 400ms
Hero tagline fades in: after typewriter completes + 200ms delay
Hero CTAs slide up + fade in: staggered 100ms each, after tagline
10.2 Scroll-Triggered Reveals
All section headings: fade in + 
translateY
(
20px → 0) when they enter viewport
Cards and list items: staggered fade in, 80ms between items
Timeline entries: slide in from left with fade
Use Framer Motion's 
whileInView
 with once: true
10.3 Typewriter Effect (Hero)
Characters appear one by one at 60ms intervals
Blinking cursor: opacity 0/1 toggle at 530ms interval
Cursor disappears 1s after typing completes
10.4 Glitch Effect (Optional — on hero name hover)
On hover of the 
hero
 name, apply a brief CSS glitch animation
Duration: 400ms, single play, do not loop
Use CSS @keyframes with clip-path or text-shadow displacement in two passes
